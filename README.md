# 🏦 ATM Simulation in Python

This project is a **Python-based ATM simulation** that mimics the basic functionality of a real ATM machine.  
It includes **authentication**, **balance check**, **deposit**, **withdrawal with note management**, and **note counting**.

---

## 🚀 Features
- 🔐 **Authentication** using card number and PIN.  
- 💰 **Check Balance** — View current account balance.  
- ➕ **Deposit Money** — Add funds and update note counts automatically.  
- ➖ **Withdraw Money** — Dispense exact amount if possible with available notes.  
- 🧾 **Count Notes** — Check how many notes of each denomination are left.  
- 🛑 **Exit** — End the ATM session safely.
